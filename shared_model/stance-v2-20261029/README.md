# 更端正的托箱演示模型 · stance-v2 · 2026-10-29

此模型用作**姿态改善的仿真演示候选**：双脚较平，躯干更直，关节运动更慢。但轻箱启动仍有失败，力矩需求也增加，不能称为全面优于 v1。保留 [stance-v1](../stance-v1-20261029/README.md) 作为目前实测启动更可靠的备选，不覆盖它。

两组评测 seed 5011、6011 合计 **94/96 次托箱及严格平脚成功**：约 0.25 kg 为 30/32，约 0.5 kg 和 1 kg 各 32/32。两次轻箱失败均发生在启动阶段。文件校验见 `SHA256SUMS.json`。

## 打开 viewer

安装方法见仓库首页。在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m lifting_lab demo --device cpu --checkpoint shared_model/stance-v2-20261029/policy.pt --mass 0.4949224923474894 --seed 2027 --seconds 3600 --viewer --paused
```

打开终端打印的网址，点 **Play**。修改负重控件后点 **应用并重置**，再播放。Linux 使用 `./.venv/bin/python`。更换重量会重新启动当前场景；单次 viewer 成功不代表该重量一定可靠。

箱子初始已置于前臂上，靠自由接触承托，没有粘接；不包含拿起箱子或从普通站姿进入托箱姿态的过程。该模型仍依赖 97 维仿真观测、输出 22 个动作，尚不能直接用于真机。

## 测到了什么

约 0.495 kg、seed 2027、20 秒 CPU 回放，稳态 `t >= 2 s`：

| 指标 | 旧 smooth-v1 | 保留的 stance-v1 | 当前 stance-v2 |
|---|---:|---:|---:|
| 左／右脚平均倾角 | 0.025°／10.215° | 0.019°／0.391° | 0.062°／1.220° |
| 左／右脚垂直支持力 | 121.61／77.32 N | 113.10／85.93 N | 111.69／87.38 N |
| 躯干平均倾角 | 2.646° | 4.136° | 1.549° |
| 腿镜像残差 RMS | 9.809° | 10.934° | 7.256° |
| 全关节速度 RMS | 0.01982 rad/s | 0.01699 rad/s | 0.00998 rad/s |
| 全关节仿真力矩 RMS | 2.096 N·m | 1.815 N·m | 2.237 N·m |

力矩 RMS 相比旧 smooth-v1 **增加约 6.76%**。镜像残差是六对腿关节原始角差的 RMS，按实际镜像符号计算，没有扣除奖励的 5° 容许区间；它不表示完全对称。这些是匹配单次回放指标，不是跨初态或重量的统计保证。

GPU seed 5011，每档 16 次、每次 20 秒：

| 箱子质量 | 托箱成功 | 严格平脚成功 |
|---|---:|---:|
| 0.247461 kg | 15/16 | 15/16 |
| 0.494922 kg | 16/16 | 16/16 |
| 0.989845 kg | 16/16 | 16/16 |

轻箱 slot 7 在 **0.26 秒**因连续 **7 个控制步**失去承托而终止。失败始终计入分母，没有用 reset 后的新回合替换。v1 同组评测为 48/48，因此本模型是姿态与启动可靠性的取舍。

选择后的 seed 6011 复核同样为轻箱 15/16、中箱 16/16、重箱 16/16；轻箱 slot 4 在 0.26 秒因连续 7 步失去承托而终止。两个失败均计入合计 96 次的分母。相比之下，保留的 v1 同一两组评测合计 96/96。

严格平脚要求先完成原托箱判据，再要求完整稳态窗口至少 95% 样本双脚同时接触，且每只脚倾角都 <5°。这个判据不额外约束躯干倾角或左右载荷相等；相关指标单独报告。
