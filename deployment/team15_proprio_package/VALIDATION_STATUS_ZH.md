# 实际验证结果与适用范围

**修正箱子局部质心后，当前官方部署场景的21条测试轨迹全部完成并通过严格站立判据。** 其中18条为20秒，另3条为60秒。没有更换模型或重新训练，也没有降低通过阈值。演示建议用0.5 kg。

## 修复了什么

旧场景适配器没有显式设置新增箱子的局部惯性坐标。编译结果中的 `body_ipos = [0.17, 0, 0.8] m` 是相对箱体的偏移，导致质心位于箱体外。现在明确设置 `ipos = [0,0,0]`、`iquat = [1,0,0,0]`，并在编译后检查质量、均匀箱体惯量和局部惯性坐标。

仅修复这项箱体物理定义并增加校验。机器人几何/物理参数、策略权重、奖励、PD、摩擦及评分阈值未改。来源checkpoint SHA256仍为：

`b0722baf7d79d513d54cb8afec74860ac4aed5296bbd8049d73ec9e4afcc1382`

修复证据见 [root_cause_report.json](reports/root_cause_report.json)。原先0.25 / 0.5 kg在0.64–0.74秒失败的报告及敏感性排查保存在 `reports/historical_bad_com/`；它们描述错误质心的旧场景，**不能继续作为当前策略或当前场景失败的结论**。

每条均完成原定1000或3000个控制步，无失败回合替换，无禁止的箱体接触；发送目标均在官方XML关节范围内。报告和同目录 `episode_*.npz` 保留逐条结果、轨迹及源码/模型/资产哈希。0.5 kg演示见 `demo/demo_0p5kg.mp4`。

**1 kg余量较小：9.624°接近10°箱体倾角阈值。** 这次通过不代表对更多扰动、摩擦变化或真实箱子都稳健，默认演示仍用0.5 kg。

## 判据保持不变

- 整段回合：箱体倾角小于10°、高度误差小于0.05 m；无跌倒、无禁止的箱体接触；两前臂向上支撑力均大于1e-6 N，连续缺双臂支撑最多允许6个控制采样。
- 2秒后的稳定阶段：双脚接触且两脚倾角均小于5°的比例至少95%；躯干倾角95分位小于5°；手臂姿态RMS误差小于0.15 rad；关节速度RMS小于0.2 rad/s。
- 整段漂移小于0.10 m；目标角在XML范围内（数值容差1e-6 rad）。完整条件以报告 `criteria` 为准。

接触支撑力和几何姿态在控制步末采样；禁止的受力接触还逐物理子步检查。这里的通过不等于每个瞬间都完全无接触间隙。

## 还不能从这些结果推断什么

本次测试使用固定尺寸和固定摩擦（箱子—前臂0.7、脚—地面1.0），箱子已在抬起的前臂上。未验证外推/碰撞、大幅初态变化、真实接触材料、偏心配重、搬放箱子、抬臂过渡或空手控制。原训练框架的1 kg失败与这份官方部署场景结果应分开报告。

本地平台为Windows、Python 3.13.14、MuJoCo 3.11.0。TA仍需在实际工作副本复跑。**包内仿真可以直接运行；真实机器人目前只提供传感器读取和候选输出检查，没有启用电机控制的硬件task。** 电机标定、增益、状态失效保护与进入/退出流程见 [TA_ONSITE_ZH.md](TA_ONSITE_ZH.md)。
