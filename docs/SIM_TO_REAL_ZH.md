# v0.4.0：前臂托箱、旧连接模式与实物对应

## 当前演示：forearms，自由接触而不是固定住

四个仿真/训练/评测 CLI 默认采用 `--support-mode forearms`。两条前臂摆成近水平，
独立六自由度方块放在其上，由机器人模型的前臂碰撞体与箱底接触。
**箱子没有 CONNECT/WELD 连接，不添加旧版手/箱碰撞排除，也没有世界固定
的隐形承重台。** 接触法向力和摩擦参与运动，箱子可以滑动、转动、脱离并掉落。

这仍是碰撞几何近似，不等于已经还原真实机器人外壳。零动作 PD 只把关节
目标留在初始姿态，不会根据负载自动学会平衡。推荐先用
`demo --support-mode forearms --viewer --paused` 查看，再单步观察；
播放后倒地不应靠暗中固定基座或绑住箱子来掩盖。

CPU 和 CUDA 均可用于该演示。重量控件会重建当前模式的质量及惯量，重置后
暂停；它不负责切换模式或估计真实摩擦。当前有前臂 PPO 训练/评测入口，但
没有已验证成功的负重策略、push 恢复结果或真机验证。下文 legacy pregrasp
是另一种物理模式；旧结果与 checkpoint 不能作为前臂模式的成果。

## 实物前臂、衬垫或平台：先确认可承重，再测量

不能因为仿真前臂碰撞体能接触箱子，就认定真实外壳或手端允许这样承重。
如果实物需要托板、衬垫或平台，先由 TA/实验室及厂家确认安装位置与载荷；
其几何、质量、重心、固定方式和与箱子的接触都必须进入模型。当前模式没有
把未经验证的托板或衬垫当作已安装硬件。

至少需要确认：

- 实际可接触表面的位置、尺寸、弧度、两侧高度与倾角；碰撞模型不能只照着
  外观颜色判断，也不能把会顶到身体的部分忽略。
- 箱底与前臂/衬垫的材料、滑动与滚动趋势、压缩和阻尼。摩擦、柔顺性需要
  合适的测量或标定，不能仅为“让箱子不掉”无限增大数值。
- 箱体与配重的总质量、重心、惯量；机器人上的托板/衬垫归入相应连杆，
  不要漏算或与箱体重复计算。
- 关节可用力矩、控制频率、延迟、脚底与地面条件，以及模型/硬件差异。

如果增加绑带、夹具或常时承重的吊绳，传力路径已改变，不能继续把结果称为
无连接的 forearms 托箱。应先改变模型并明确记录新模式，而不是迁就旧画面。

## Legacy pregrasp：预先连接的双手持物，不是真实抓握

以下保留旧模式说明。只有明确指定 `--support-mode pregrasp` 的命令使用这套连接；
不适用于默认 forearms。

方块是有质量、惯量和重力的独立刚体，不是贴在画面上的装饰，也没有加到机器人胸部质量上。左右手各有一个 MuJoCo `CONNECT` 连接点，分别与方块两侧的连接点对应。

`CONNECT` 像球关节式的点连接：约束两个点靠在一起，不直接锁定相对朝向。若两个手部连接点的位置保持不变，方块仍可绕这两点的连线转动。因此它**不是完全焊死的 WELD，也不是靠手指摩擦夹住**。[MuJoCo 官方定义](https://mujoco.readthedocs.io/en/stable/XMLreference.html#equality-connect)

legacy 连接一直启用，有数值柔顺性，但没有握力上限、滑移、断裂或主动松开机制。`grip_failed` 的 15 cm 位置误差仅用于终止仿真，不能理解为真实夹具的脱落模型。该模式的手与方块相关碰撞对被排除，方块靠连接约束向手臂传力；不是黑色手柄的接触摩擦在承重。

### Legacy 几何与质量，不是前臂模式的摆放尺寸

| 项目 | legacy pregrasp 模型 |
|---|---|
| 方块长宽高（模型 x/y/z） | 20 × 40 × 12 cm |
| 左右连接点间距 | 约 50 cm |
| 连接点连线相对方块重心 | 高约 3 cm |
| 初始箱体中心 / 连接点高度 | 约 61 / 64 cm |
| 初始姿态的箱心（世界坐标） | 约 (0.23, 0, 0.61) m；seed reset 可整体平移/转向 |
| 黑色手柄 | 仅外观，无质量、无碰撞 |
| 惯量假设 | 均匀实心箱；重量变化时形状和重心不变，惯量按质量缩放 |

具体实现是 `src/lifting_lab/model.py` 的 `initial_grip_geometry()`、`make_payload_spec()` 和 `add_grip_constraints()`。不要把上表当作厂家安装尺寸或承载标准。

### 如果实物主动选择固定连接，而不是自由托箱

只有在研究任务明确改为固定负载时，才考虑**经实验室/厂家确认可用的双侧机械夹具**，将负载接到左右手端的承力位置。这不是 forearms 的必要部件，也不与自由接触等价。不要仅靠胶带、外壳摩擦或随意捆扎就假定与 legacy CONNECT 等价。实际接口、允许载荷、关节力矩和结构强度尚未验证，本文件不提供可直接施工的尺寸或安全承重值。

不同固定方式对应不同模型：

| 实物固定方式 | 与 legacy CONNECT 的对应 / 如何调整 |
|---|---|
| 两侧可靠、允许转动的点连接 | 最接近 legacy CONNECT；还需匹配连接点位置、转动范围、摩擦和柔顺性 |
| 螺栓/法兰/托架刚性固定，能传递扭矩 | 不是 legacy CONNECT；应按最终结构建刚性/柔性连接。不能不看机构就把两手各加一个硬 WELD，避免闭链过约束 |
| 软绑带、绳索 | 需要长度、松弛、仅拉不压、弹性等模型；不能当球关节或刚性连接 |
| 真正手指/夹爪摩擦夹持 | 需要接触、摩擦、夹持力限制、滑落与释放；当前包没有这些能力 |
| 固定在胸部/腰部，而不是手上 | 负载传力路径和力臂改变；应改为躯干附加负载任务，不能沿用双手持物结果 |

建议的下一步是：把机器人实际手端照片、允许使用的安装接口、夹具设计或 CAD 给 TA/实验室负责人确认，再据此修改仿真。不是为了迁就当前仿真去做一个未经验证的实物结构。

### Legacy 连接还原还需要测量

1. **总质量**：箱体、配重和附着其上的夹具都计入；装在机器人手端的夹具质量应归到对应机器人连杆，不能漏掉或重复计算。
2. **重心与惯量**：同重量不等于同动力学。集中在底部的铁块与均匀箱体惯量不同；配重移动会改变重心。按真实装配的 CAD/测量数据更新模型，不只调 viewer 的 kg。
3. **连接点与自由度**：两手连接间距、相对姿态、允许转轴/角度、间隙、摩擦及松紧程度。当前 `solref/solimp` 是数值求解参数，不是已测得的夹具刚度。
4. **几何接触**：实物是否会顶到胸、前臂或腿；手柄若参与承重/接触，要补上真实碰撞形状。legacy 中被排除的手部接触不能代表真实接触力。
5. **执行器与测试条件**：控制频率、延迟、扭矩限制、摩擦、脚底和地面条件；仿真正常不能保证硬件正常。

## 两种模式共同的真机边界

- viewer 的 **0–10 kg 不是 K1 额定负载**。不要据此直接给真机加到 10 kg。
- 当前包提供仿真、研究训练和评测，不是可部署的负重控制器。没有确认安全的上机步骤或夹具方案。
- 真实测试须经 TA/实验室负责人批准，使用厂家允许的安装位置、防坠保护、隔离区域及急停安排。Booster 官方提示：CUSTOM 模式由用户代码控制全部关节，易失衡，开发时应使用吊架保护，先做仿真验证。[官方安全说明](https://docs.booster.tech/docs/product-manual/k1/getting-started/safety-warnings/)
- 防坠保护不是让人站在旁边用手接机器人。当前仿真没有承重吊索：若要比较无支撑条件，保护装置不能在正常测量阶段承担负载或施加未建模约束。实际安全安排仍由实验室负责人确定；一旦吊架/绳索承重，应停止将该段视为无支撑数据，并记录或建模其作用，不能报告成自由站立成功。

两种模式都只是仿真研究工具：forearms 研究自由接触，legacy pregrasp 研究预先连接的负载。必须先确认真实支撑方式并标定模型，不能依据演示画面直接上机。
