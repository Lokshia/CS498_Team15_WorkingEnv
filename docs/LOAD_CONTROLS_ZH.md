# 同一个 viewer 中切换空手、托箱和重量

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m lifting_lab.mode_viewer --port 8082
```

浏览器打开 `http://127.0.0.1:8082/`。Linux 把解释器改为 `./.venv/bin/python`；GPU 预览可加 `--device cuda`。安装步骤仍见根目录 README。

1. 在 **场景与重量 / Load controls** 中选择 **空手 / No box** 或 **托箱 / With box**。
2. 托箱时，在 **箱子重量 (kg)** 输入数值，例如 `0.5`。
3. 点击 **应用并重置 / Apply & Reset**，等控件恢复可用。
4. 点击 **Play**。再次改设置时，重复上述步骤。

空手模式真正删除箱体，重量框禁用；托箱模式才有自由接触前臂的箱体。不要用托箱的 `0 kg` 代替空手，托箱框只接受 `0.001–10 kg`。箱子没有粘住，可以滑落。这个输入范围不是机器人额定承重。

当前默认搭配：

- 空手：`shared_model/empty-hand-v1-20261030/policy.pt`，72 维 Actor 输入。
- 托箱：`shared_model/stance-v2-20261029/policy.pt`，97 维 Actor 输入，训练重量约 `0.247–0.990 kg`。

每份权重须保留旁边的 `experiment.json`。界面自动选择相应模型，不会把一个模型硬用于另一种输入。两个模型的训练和评测结果见各自目录；本次只是接入操作控件，没有再次训练。

**应用设置会重建质量、惯量和物理场景，回到初始姿态并暂停。不是运行中接箱、卸箱或连续切换控制器。** 此功能适合比较不同条件下的独立仿真回放，不能直接作为真机上下货程序。

录像时不能切换模式或重量，先停止录像并等保存完成。每次应用的模式、实际物理质量、观测维度和模型 SHA 会写入本次输出目录的 `revision_NNN/world.json`；该条件下的录像保存在对应 `revision_NNN/recordings/`，避免混淆。程序会在终端打印网址；默认输出位于 `outputs/日期时间_load_viewer/`。

失败时保留原场景并重置暂停，界面会说明失败原因。修改重量超出训练范围时会提示；范围内也不代表每次都能保持稳定。界面回放不是独立成功率评测。
